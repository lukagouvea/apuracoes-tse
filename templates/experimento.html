Reprodução dos experimentos

Código, configuração, fontes e resultados de referência ficam no repositório.

  1. Preparar o ambienteEscolha a receita CPU pública ou a imagem GPU original. Defina o diretório do dataset no .env.
  2. Baixar, preparar e auditarO snapshot único preserva os __RAW_FILES__ arquivos oficiais, seus nomes e SHA-256. Os ZIPs somam aproximadamente __RAW_GIB__ GiB.
  3. Executar uma saída novaA grade usa 0,1%, 0,2%, 0,5% e 1%–100%. Empates de horário entram juntos.
  4. Comparar com a referênciaO script confere os snapshots e as projeções dos três anos. Os dados de entrada ficam montados somente para leitura.
./scripts/cpu.sh --read-only scripts/reproduce.py \
  --output reports/runs/reproducao-01 \
  --compare-to reports/cpu-study-20261107
